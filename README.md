# Movie Explorer

Movie Explorer is a React-based movie discovery website. Users can search for movies and TV shows, view movie information, and see detailed information about selected movies.

## Features

* Home page with Hero section
* Movie search
* Responsive movie grid
* Movie cards
* Movie details modal
* React Router navigation
* TVMaze API integration
* Responsive design for mobile and desktop

## Technologies Used

* React
* JavaScript
* React Router
* CSS
* TVMaze API
* Vite

## How to Run

1. Clone the repository
2. Open the project folder in the terminal
3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL shown in the terminal.

## API

This project uses the TVMaze API:

https://api.tvmaze.com/
